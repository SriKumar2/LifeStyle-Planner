# 2. Use Cloud Nine on Windows

Cloud Nine installs from your browser and then behaves like any other Windows app: its own window, a taskbar icon, and a Start menu entry. There’s nothing to download.

You need the **link** and **passcode** from whoever set it up (see [Setup](1-SETUP.md)).

## Install with Microsoft Edge (built into Windows)

1. Open **Microsoft Edge** and go to your Cloud Nine link.
2. Type your **passcode** and click **Open my planner**.
3. Click the **⋯** menu (top right) → **Apps** → **Install Cloud Nine**.
   - Or click the small **app icon** that appears at the right end of the address bar.
4. Click **Install**.
5. Edge offers a few options. Tick the ones you like:
   - **Pin to taskbar**
   - **Pin to Start**
   - **Create Desktop shortcut**
   - **Auto-start on device login** opens your planner every time you turn on the computer.
6. Click **Allow**.

Cloud Nine now opens in its own window. You stay signed in for 180 days.

## Install with Google Chrome

1. Open **Chrome** and go to your Cloud Nine link, then sign in.
2. Click the **install icon** (a screen with a down arrow) at the right end of the address bar.
   - Or open the **⋮** menu → **Cast, save, and share** → **Install page as app**.
3. Click **Install**.
4. To pin it, right-click the Cloud Nine icon on the taskbar → **Pin to taskbar**.

## Handy things to know

- **Ctrl + K** opens Cloudy, the AI helper, from anywhere.
- **Updates install themselves.** If something looks out of date, close the Cloud Nine window and open it again.
- **Night mode:** click the moon button at the top right.
- **Notifications:** when you start a focus timer, Windows may ask whether Cloud Nine can show notifications. Click **Allow** to get a ping when the 25 minutes are up.
- **Works on several computers:** install it the same way on each one. They all share the same planner.

## Uninstall

- **Edge:** open `edge://apps` in Edge, find Cloud Nine, click **⋯** → **Uninstall**.
- **Chrome:** open Cloud Nine, click **⋮** at the top of its window → **Uninstall Cloud Nine**.

Uninstalling only removes the app from that computer. The planner and its data stay online.
