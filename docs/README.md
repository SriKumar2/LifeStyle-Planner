**Quick version for the person who will use it:**

1. Whoever sets it up sends you **a link** (something like `https://cloud-nine.yourname.workers.dev`) and **a passcode**.
2. On Windows, open the link in **Microsoft Edge** → sign in → **⋯ menu → Apps → Install Cloud Nine**.
3. On iPhone, open the link in **Safari** → sign in → **Share → Add to Home Screen**.
4. Everything you do on one device shows up on the other.
